# Agent / SSH / Vim 黑盒测试记录

测试日期：2026-09-11 至 2026-09-12。平台：Windows、Electron 38、Node 22.20.0。

## 测试方式

使用独立应用数据目录、回环地址上的临时 OpenSSH 容器，以及本地模拟模型。SSH、Vim、应用界面、系统剪贴板均真实运行；没有连接用户服务器或调用付费模型。

- 原生右键菜单、拖选和系统复制使用 Windows 鼠标、键盘操作。
- 可重复回归通过 Chromium 输入事件点击、输入；只读取 DOM 定位可见控件和核对文字，不调用 Angular 组件、应用服务、按钮处理函数或 xterm 内部状态。
- 模拟模型产生可控的命令、503 和不完整流；通过模型收到的真实工具结果及容器文件核对执行结果。
- 之前的 `test-native-agent-ui.cjs` 包含内部接口调用，属于灰盒验证，与本记录的黑盒测试区分。

## 发现并修复

**审批按钮被挤出窗口。** 在 1280×783 窗口中，历史和输入框占据底部空间后，“允许执行”的中心位置达到 y=910。用户无法直接点击，看起来像 Agent 卡住。之前直接调用审批函数的测试没有发现这个问题。

修复：有待处理审批或输入表单时，暂时隐藏历史和普通输入框，优先显示交互内容。保留现有按钮与操作方式。通过真实点击在 1280×783、760×600 两种尺寸复测。

代码：`tabby-ai/src/ui/agent-dock.component.pug`。证据：`01-approval.png`、`02-approval-fixed.png`、`04-narrow-approval.png`。

## 回归脚本

先完成项目构建，并确保 Docker 正在运行、本机已有测试镜像 `ash-native-agent-test:local`。该镜像必须提供 SSH、Vim，以及 ashbash / ashzsh / ashfish 三个测试用户，支持 `ASH_TEST_PASSWORD` 环境变量。测试脚本不会自动连接现有用户配置。

在两个终端分别运行：

```powershell
yarn test:agent:blackbox:fixture
yarn test:agent:blackbox
```

第一条启动独立应用和临时服务；第二条执行 8 个可重复黑盒场景：无 PTY / EOF、退出状态、拒绝、修改审批、503、流中断、停止、窄窗口长历史。原生菜单、剪贴板、120 秒超时、多标签及重启等按上表操作，不冒充已包含在这 8 项自动化中。

结束夹具可在启动终端按 Ctrl+C，或向 `.build-cache/agent-blackbox-current.json` 中 controlPort 的 `/stop` 发送 POST。仅清理本次测试应用和容器。
